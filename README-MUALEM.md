# MUALEM — חבילת מסירה ראשונית

חבילה זו מרכזת את הקבצים הזמינים בשיחה עבור מרכז השליטה MUALEM: מפת המערכות, שמונה קובצי SQL ותמונת ממשק להמחשה. היא **אינה קוד המקור המלא של האתר הפעיל** ואינה כוללת קוד מקור של אתרי אבלות ישראל, תל״מ או Together.

## תוכן
- `MUALEM-system-map-2026-09-23.md` — מפת מערכות ומצב אימות כפי שתועד ב־23.9.2026.
- `mualem-*.sql` — טיוטות תשתית למסד נתונים; חלקן מיועדות לסביבות שונות ועלולות להיות חלופיות, לא רצף מיגרציות להרצה.
- `ממשק MUALEM חכם בעברית.png` — תמונת המחשה של ממשק.

## חשוב לפני שימוש
אין להריץ את קובצי ה־SQL על מסד נתונים פעיל. יש לבדוק תלות, סדר, התאמה לסביבה והרשאות לפני כל הרצה. אין להעלות לכאן סודות, קובצי `.env`, מידע אישי או נתוני לקוחות. יש לאתר ולייצא בנפרד את קוד המקור המקורי של האתר מתוך סביבת הפיתוח.
